# Контекст на проекта — Image Filter Pipeline (PHP MVC)

Ти помагаш на backend разработчик с PHP MVC проект. Проектът е система за обработка на изображения чрез пайплайни от филтри. По-долу е целият необходим контекст.

---

## 1. Пагинация на постове

**Въпрос:** При заявки, връщащи постове, връща ли се всичко наведнъж или частично?

**Отговор:** Трябва да се ползва пагинация. Връщането на всички постове е лоша практика в production.

**Имплементация:** Параметри в URL — `?page=1&limit=10`

**SQL логика:**
```sql
-- Страница 2, по 10 поста
SELECT * FROM posts ORDER BY created_at DESC LIMIT 10 OFFSET 10;

-- Формула за OFFSET:
-- OFFSET = (page - 1) * limit
```

**Концепция:** Infinite Scroll — при достигане на края на страницата, JS прави нова заявка за следващата страница.

## 2. Спецификация на филтрите

Филтрите се записват в таблица `pipeline_steps` с поле `filter_id`. Параметрите се подават като JSON в поле `params`.

### Пълен списък

| ID | Филтър | Параметър | Тип | Диапазон | UI елемент |
|----|--------|-----------|-----|----------|------------|
| 1 | Gaussian Blur | `intensity` | integer | 1–50 | Slider |
| 2 | Grayscale | — | — | `{}` | Toggle |
| 3 | Sepia | — | — | `{}` | Button |
| 4 | Brightness | `level` | integer | -255 до 255 | Slider (0 в центъра) |
| 5 | Contrast | `level` | integer | -255 до 255 | Slider (0 в центъра) |
| 6 | Saturation | `level` | integer | -100 до 0 | Slider |
| 7 | Hue Rotate | `angle` | integer | 0–360 | Dial / Slider |
| 8 | Vignette | — | — | `{}` | Button |
| 9 | Digital Noise | `intensity` | integer | 1–100 | Slider |
| 10 | Edge Detect | — | — | `{}` | Button |

### Детайли по филтър

**ID 1 — Gaussian Blur**
- Описание: Замъглява изображението
- `params`: `{ "intensity": 5 }`
- Валидация: integer, 1 (слаб) до 50 (много силен)

**ID 2 — Grayscale**
- Описание: Премахва всички цветове (черно-бяло)
- `params`: `{}`

**ID 3 — Sepia**
- Описание: Топъл ретро кафеникав нюанс
- `params`: `{}`

**ID 4 — Brightness**
- Описание: Увеличава/намалява светлината
- `params`: `{ "level": 20 }`
- Валидация: integer, -255 (черно) до 255 (бяло), default: 20

**ID 5 — Contrast**
- Описание: Регулира разлика между тъмно и светло
- `params`: `{ "level": 30 }`
- Валидация: integer, -255 до 255 (положително = повече контраст)

**ID 6 — Saturation / Desaturation**
- Описание: Намалява цветовата наситеност
- `params`: `{ "level": -50 }`
- Валидация: integer, -100 (почти черно-бяло) до 0 (оригинал)
- Бележка: backend поддържа САМО десатурация (отрицателни стойности)

**ID 7 — Hue Rotate**
- Описание: Ротация по цветовото колело
- `params`: `{ "angle": 180 }`
- Валидация: integer, 0–360 градуса (0 и 360 = без ефект)

**ID 8 — Vignette**
- Описание: Затъмнява краищата, акцентира центъра
- `params`: `{}`

**ID 9 — Digital Noise**
- Описание: Добавя зърнест филмов ефект (случайни пиксели)
- `params`: `{ "intensity": 15 }`
- Валидация: integer, 1–100 (препоръчително: 5–20 за приятен ефект)

**ID 10 — Edge Detect**
- Описание: Оставя само контурите/линиите на обектите
- `params`: `{}`

## 3. Структура на POST заявка за запис на пайплайн

Endpoint приема масив `steps`, наредени по `step_order`.

```json
{
  "name": "Ретро Филмов Пайплайн",
  "steps": [
    {
      "step_order": 1,
      "filter_id": 2,
      "sub_pipeline_id": null,
      "params": {}
    },
    {
      "step_order": 2,
      "filter_id": 4,
      "sub_pipeline_id": null,
      "params": { "level": 15 }
    },
    {
      "step_order": 3,
      "filter_id": 8,
      "sub_pipeline_id": null,
      "params": {}
    }
  ]
}
```

**Правила:**
- `step_order` е поредният номер на изпълнение (1, 2, 3...)
- `filter_id` съответства на ID-тата от таблицата по-горе
- `sub_pipeline_id` е `null` при обикновен филтър
- `params` е `{}` за филтри без параметри

## 4. Контекст за backend

- Платформа: PHP MVC
- Компонент за изпълнение на пайплайни: `PipelineRunner`
- Параметрите се съхраняват в `pipeline_steps.params` като JSON
- Пагинацията трябва да е добавена в `PostController` (ако още не е)
